Published

Enhanced Crack Detection using GOA-UNet Segmentation

🔗
Journal: Measurement (Elsevier)
Volume: 263 (2026)
DOI: 10.1016/j.measurement.2025.120197
Published: December 24, 2025
My Role: Co-author (Writing, Visualization, Validation, Methodology)

Abstract

This paper proposes a novel GOA-UNet model for automated crack detection in civil infrastructure. The approach integrates multiple state-of-the-art techniques to achieve robust detection and geometric measurement of structural cracks.

Key Components

  • Grasshopper Optimization Algorithm (GOA) for hyperparameter tuning
  • GAN-based data augmentation for synthetic crack image generation
  • Power Law Transformation for contrast enhancement
  • Connected Component Analysis (CCA) for geometric measurements

Results

Crack Detection Accuracy: 98.5%
F1-Score: 84.12%
IoU (Intersection over Union): 72.92%
Inference Speed: 22.2 FPS (Real-time capable)
Cross-Dataset Generalization: 95.27% performance retention

Co-Authors
